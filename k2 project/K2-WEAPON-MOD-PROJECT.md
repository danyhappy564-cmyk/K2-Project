## 1. 모델 — 확인 완료

### 1.1 라이선스 (해결됨)

`license.txt` 에 명시:

```
license type: CC-BY-4.0  (http://creativecommons.org/licenses/by/4.0/)
requirements: Author must be credited. Commercial use is allowed.
```

**배포물에 반드시 아래 문구를 그대로 넣어야 한다** (license.txt 가 요구하는 원문):

```
This work is based on "K2C3" (https://sketchfab.com/3d-models/k2c3-39bb1eeed4b949c7a620b16667262faf)
by GAMGO (https://sketchfab.com/gamgo_studio) licensed under CC-BY-4.0
(http://creativecommons.org/licenses/by/4.0/)
```

제작자가 Sketchfab 댓글로도 "다운로드 가능한 모든 모델은 제한없이 이용 가능" 이라고
직접 남겼다. **그 댓글은 스크린샷으로 보관해 둘 것** (계정/모델이 내려갈 수 있음).

### 1.2 확보한 변형 3종

| 모델 | 실제 계보 | 특징 |
|---|---|---|
| K2 | 원본 K2 | 플라스틱 리브 핸드가드, 고정 가늠쇠, 측면 접이식 고정 개머리판, **레일 없음**, 465mm |
| K2C3 | 사실상 **K2C1** | 쿼드레일 핸드가드, 상부 피카티니, AR식 신축+접이 개머리판, 465mm |
| K2C4 | 사실상 **K2C** (단축) | 쿼드레일, 상부 레일, 신축 개머리판, **310mm 단축 총열** |

> `K2C3` / `K2C4` 는 공식 제식 명칭이 아니다. 공식 계보는 K2 → K2C(단축) → K2C1(레일).
> 제작자 임의 명명으로 보이며, 모드에서 어떤 이름을 쓸지는 자유.

포맷: **FBX / glTF / GLB / USDZ**. → Unity 작업엔 **FBX** 를 쓸 것.

### 1.3 glTF 분석 결과 (K2C3 기준, 실측)

```
generator : Sketchfab-13.74.0 / glTF 2.0   (원본 FBX 명: K2C3_AR.FBX)
nodes 9 / meshes 2 / skins 없음 / animations 없음 / materials 2 / textures 8
```

| 항목 | 값 | 평가 |
|---|---|---|
| 삼각형 | **12,749** (10,039 + 3,801 정점) | 모드 무기로 충분. 바닐라보단 단순 |
| 메시 | 2개 — `Object001`(8,657 tri), `Body`(4,092 tri) | 기능별이 아니라 **앞/뒤 + 머티리얼** 분할 |
| **loose part** | **212개** (194 + 18) | ⭐ **핵심. 부품 셸이 살아있음** |
| 본(리깅) | **없음** | 새로 만들어야 함 |
| 애니메이션 | 없음 | EFT 는 자체 애니를 쓰므로 무관 |
| 정점 속성 | `POSITION` `NORMAL` `TANGENT` `TEXCOORD_0` | **노멀맵 재굽기 불필요** |
| 텍스처 | 2048² PBR ×2 세트 (baseColor / metallicRoughness / normal / emissive) | 그대로 활용 가능 |

**212 loose part 가 이 프로젝트의 성패를 갈랐다.** 통짜 메시였다면 3D 툴로 잘라내고
구멍 막고 UV 수리까지 해야 했는데, 셸이 분리돼 있으므로 블렌더에서
`P` → `By Loose Parts` **한 번으로 212개 오브젝트가 된다.** 남는 일은 자르기가 아니라
**고르고 묶기**.

### 1.4 부품 위치 지도 (0% = 총구, 100% = 개머리판 끝, 월드 좌표 실측)

| 구간 | 삼각형 | 추정 정체 |
|---|---|---|
| 0 ~ 50% | 676 | **총열** (가늘고 긴 원통, 단면 0.15×0.15) |
| 16 ~ 25% | 486 / 156 / 96 / 94 | 가늠쇠 · 가스블록 |
| 26 ~ 70% | **2,048** | **쿼드레일 핸드가드** (최대 조각) |
| 30 ~ 50% | 작은 조각 **139개** | 피카티니 레일 이빨 |
| 50 ~ 74% | **1,091** | **총몸(리시버)** |
| 51 ~ 65% | 135 / 117 / 90 | **장전손잡이 · 노리쇠 후보** ← 확인 필요 |
| 64 ~ 73% | 390 | 권총손잡이 |
| 72 ~ 93% | 422 | 버퍼튜브 |
| 85 ~ 100% | 560 / 114 | **개머리판** |

**핸드가드 · 총열 · 총몸 · 개머리판이 전부 독립 셸** → 부품 교체(모듈) 구조 가능.

### 1.5 주의할 점

- 12,749 tri 를 **부품별로 쪼개면 각 파츠는 저폴리**가 된다. 1인칭으로 가까이 보면 티가 남
- 단면 두께 `0.02` 수준의 얇은 조각 존재 → **단면(single-sided) 지오메트리**일 수 있음.
  Unity 에서 뒷면이 비치면 그 조각만 두께를 주거나 양면 셰이더
- 모델에 **탄창이 없음**(빈 탄창실). EFT 에선 탄창이 별개 아이템이므로 **오히려 정상**

## 2. K2 실물 스펙 → EFT 매핑

| 항목 | 실물 | EFT 반영 |
|---|---|---|
| 탄약 | 5.56×45mm NATO | `Caliber556x45NATO` |
| 총열 | 465mm (18.3″) / 단축 310mm (12″) | 탄속 ↑, 인체공학 ↓ |
| 무게 | 3.26kg (K2) / 3.6kg (K2C1) | 조립 완성 기준 역산 |
| 연사속도 | 700~900 rpm | `bFirerate` 750 |
| 탄속 | 915 m/s (K100탄) | 총열 배율 |
| 작동방식 | **장스트로크 가스 피스톤** + 회전 노리쇠 | M4(직충식)보다 반동·총구상승 ↑ |
| 탄창 | **STANAG** | **M4 탄창 그대로 재사용** — 신규 에셋 불필요 |
| 개머리판 | 측면 접이식 (K2) / AR 신축+접이 (K2C1) | `Foldable: true` |
| 유효사거리 | 600m | `SightingRange` |

**클론 베이스: HK416A5 권장.** 5.56 + 가스 피스톤 + STANAG + 접이식 개머리판 + 풀오토로
슬롯 구조가 K2 에 거의 1:1. M4A1 은 직충식이라 반동 성격이 다르고 개머리판이 안 접힘.

> ⚠️ 클론 원본의 템플릿 ID 는 **실제 4.1.5 DB 에서 확인할 것.** 기억에 의존하지 말 것.

## 3. 설계 — 총 1정 + 부품 교체

세 모델이 **총몸·권총손잡이·방아쇠울을 공유**하고 가구만 다르다. 그래서 별개 총 3정이
아니라 **총 1정 + 갈아끼우는 부품**으로 간다. 이게 타르코프답고 파밍 재미도 생긴다.

| 슬롯 | 선택지 | 부품 출처 |
|---|---|---|
| `mod_barrel` | 465mm / **310mm 단축** | K2·K2C3 / K2C4 |
| `mod_handguard` | 플라스틱 리브 / **쿼드레일** | K2 / K2C3·K2C4 |
| `mod_stock` | K2 접이식 고정 / **AR 신축+접이** | K2 / K2C3·K2C4 |
| `mod_muzzle` | K2 소염기 / 표준 5.56 총구장치 | — |
| `mod_magazine` | **STANAG (기존 M4 탄창 재사용)** | 만들 필요 없음 |
| `mod_sight_front`/`_rear` | 고정 가늠쇠·가늠자 / 레일 BUIS | K2 / 공용 |
| `mod_mount` | **쿼드레일 핸드가드에만** (손전등·레이저·전방손잡이) | K2C3·K2C4 |
| `mod_scope` | **상부 레일에만** | K2C3·K2C4 |

**결과**: 1번(원본 K2) 구성으로 싸게 사서 → 레일 핸드가드 + 신축 개머리판 + 단축 총열을
물려 → 3번(K2C) 으로 개조. 총몸을 한 번만 잘라내면 세 모델에 다 쓴다.

## 4. 작업 분담

| 단계 | 담당 | 난이도 | 비고 |
|---|---|---|---|
| ① 모델 평가 | **완료** | — | 이 문서 1장 |
| ② 블렌더: loose part 분리 → 기능별 묶기 | 사용자 | 중 | **자르는 게 아니라 고르는 작업** |
| ③ Unity: EFT 프리팹 계층 + `mod_*` 트랜스폼 + 번들 빌드 | 사용자 | **높음 — 진짜 산** | Unity 버전 정확히 맞출 것 |
| ④ 서버 모드 전부 | **Claude** | 중 | **②③ 과 무관하게 지금 시작 가능** |

### ③에서 필요한 것 (EFT 무기 프리팹 요구사항)

- `mod_*` 부착 지점 트랜스폼 (없으면 부착물 자체가 불가능)
- `fireport` (총구 화염), `shell_eject` (탄피 배출)
- 손 IK 타겟 — 안 맞으면 캐릭터가 총을 허공에 듦
- 노리쇠 · 장전손잡이 = **움직이는 부품**이므로 반드시 별개 오브젝트
- EFT 셰이더로 머티리얼 변환 (Sketchfab 은 PBR 표준)
- LOD + 콜라이더
- 정확한 Unity 버전으로 AssetBundle 빌드

### ④ 범위 (Claude 담당)

- 아이템 템플릿 (HK416A5 클론 + `_props`)
- 슬롯 정의 · 충돌 아이템 · 탄도
- 핸드북 엔트리, **로케일 EN + KR**
- 상인 어사트, 플리 가격, (선택) 봇 로드아웃
- SPT 4.1 함정 대응: **아이템 등록은 `OnLoadOrder.Preload`** 외 KB 참조

## 5. 권장 진행 순서 — "리스킨 먼저"

서버 쪽은 모델이 있든 없든 **똑같다.** 그래서 이 순서가 낭비가 없다:

1. **지금**: 서버 모드 완성 + 프리팹 경로를 HK416 으로 걸어둠
   → **오늘 바로 게임에 K2 스탯으로 나온다.** 모양만 HK416
2. **나중**: 번들이 나오면 **프리팹 경로 문자열 하나만 교체**
   → 나머지는 손 안 댐

사용자가 Unity 를 붙들고 있는 동안 나머지는 이미 다 돌아가는 상태가 된다.

## 7. 환경 메모
